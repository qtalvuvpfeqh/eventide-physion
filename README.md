## Overview

Eventide Physion separates audio into transient and tonal components, enabling independent processing of the attack transients and sustained tones of any sound for unique mix treatments.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eventide Physion** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Separation Engine** | AI-driven transient/tonal separation with adjustable crossover |
| **Independent FX** | Apply different effects chains to the separated components |
| **Blend** | Mix transient and tonal components back at any proportion |
| **Creative** | Combine different pitch shifting and reverb on tonal vs. transient parts |
